关于 YiPuzzles Web

YiPuzzles Web 是 Android 版 YiPuzzles 2048 的网页版，沿用 Material You 设计语言，无广告、无追踪、完全离线可玩。

玩法

  • 滑动或按方向键，所有方块向同一方向移动。
  • 两个相同数字的方块碰撞后合并为它们的和。
  • 拼出 2048 即获胜，之后仍可继续挑战更高分。
  • 棋盘填满且无法合并时游戏结束，可随时撤销。

快捷键

  • ↑↓←→ / WASD 移动
  • Z 撤销　R 重新开始

数据

分数、最高分与对局进度按棋盘大小分别自动保存在本机浏览器中。

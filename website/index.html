Features

麻雀虽小，五脏俱全

商店里的 2048 要么塞满广告与账号体系，要么只有一个 4×4 棋盘。YiPuzzles 选择了另一条路。

🧩 经典 2048 玩法

  • 向任意方向滑动，数字块合并为下一个 2 的幂
  • 合成 2048 即可获胜，还可继续冲击更高分
  • 支持撤销一步与即时重新开始
  • 进度自动保存，随时回到上次的棋盘

🎯 四种棋盘大小

  • 经典 4×4，外加 5×5、6×6、7×7
  • 更大的棋盘，更长的对局，更烧脑的挑战
  • 主页棋盘预览实时应用你当前的配色方案

📊 详细的统计数据

  • 按棋盘大小分别记录，互不混淆
  • 最大数字、最高分、游戏时长
  • 各方向滑动次数、撤销次数、单次滑动用时

🎨 Material You 设计

  • 动态取色：从壁纸种子色生成和谐配色（Android 12+）
  • 三套数字块配色：Material You / 2048 经典 / 深蓝
  • 浅色 · 深色 · 跟随系统，边缘到边缘全屏显示
  • 可选的移动与合并动画，反馈流畅舒适

🔒 100% 隐私 · 离线 · 无广告

  • 零权限——应用根本无法触碰自身之外的任何东西
  • 无广告、无跟踪、无统计、无账号、无需联网
  • 依据 GPL-3.0 许可证开源

🌍 多语言本地化

  • 内置 简体中文 与 English
  • 随附新手教程与常见问题解答
  • 欢迎社区贡献更多语言的翻译

⚙️ 贴心的玩家选项

  • 游戏时保持屏幕常亮
  • 纯滑动操作——不会误触，单手即可游玩

Under the Hood

为什么是 YiPuzzles？技术内幕

01

零权限架构

清单文件不声明任何权限；棋盘、分数与统计全部存储在本机。游戏 100% 离线运行——代码里没有需要审计的东西，自然也无权可授。

02

Material You 动态主题

在 Android 12+ 上，整套配色从壁纸种子色派生，棋盘、数字块与主页预览与设备浑然一体。偏爱固定外观？随时切回 2048 经典 或 深蓝 方案。

03

测试保障与持续集成

游戏核心（棋盘状态、合并与计分）保持小而纯粹，由 JUnit / Robolectric 单元测试覆盖；GitHub Actions 每次推送自动构建并发布 nightly，始终有新鲜、可复现的下载。

Build from Source

从源码构建

想审查每一行代码，或动手改点什么？三条命令即可得到属于你自己的 APK。

☕ JDK 17+ 🛠️ Android SDK（API 34） 🐘 Gradle Wrapper 已内置
1克隆仓库 
git clone https://github.com/lingyicute/YiPuzzles.git
cd YiPuzzles
2构建 Debug APK（开发调试） 
./gradlew assembleDebug
3构建 Release APK（正式发布） 
./gradlew assembleRelease

构建产物位于 app/build/outputs/apk/，文件名形如 yipuzzles-<variant>-v<version>.apk。提交代码前请确保 ./gradlew test 全部通过。
